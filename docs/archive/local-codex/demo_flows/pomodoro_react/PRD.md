# PRD: React Pomodoro Timer

## Problem

Create a clean, small productivity demo that shows the agent can deliver a polished utility app without scope creep.

## Goals

- Build a Pomodoro timer in React
- Keep the UI crisp and easy to understand
- Make the timer behavior reliable

## Non-goals

- Account systems
- Cross-device sync
- Calendar integration

## Users

- Demo viewers
- Developers validating a compact frontend build

## Requirements

- Work and break timer states
- Start, pause, reset controls
- Session count or cycle indicator
- Minimal visual polish

## Success Criteria

- Timer runs locally
- Controls behave predictably
- README explains how to run the app

## Risks

- Timer drift or state bugs
- Over-designing the UI
- Adding unrelated features like task management
