# React Pomodoro Timer Demo

This demo shows a small productivity timer built in React.

## Demo goal

Prove that the agent can deliver a simple, polished utility app with predictable state and a clear run story.

## Run shape

```bash
agent start "Build a Pomodoro timer using React"
```

## Acceptance

- Timer counts down
- Controls are obvious and reliable
- Break/work cycling is visible
- The app is simple enough to explain quickly
