# React Snake Game Demo

This demo shows a simple playable snake game built in React.

## Demo goal

Prove that the agent can take one prompt, produce a small interactive app, and keep the implementation bounded.

## Run shape

```bash
agent start "Build a simple snake game using React"
```

## Acceptance

- Game starts and accepts arrow-key input
- Food spawns and increments score
- Collision ends the game
- Restart works without a reload
