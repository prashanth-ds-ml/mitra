# PRD: React Snake Game

## Problem

Create a polished, easy-to-demo game project that proves the agent can scaffold a small frontend app cleanly.

## Goals

- Build a playable snake game in React
- Keep the scope narrow enough for a fast demo
- Produce a clear README and implementation order

## Non-goals

- Multiplayer
- Backend services
- Persistent high score storage

## Users

- Demo viewers
- Developers validating the agent workflow

## Requirements

- React UI
- Keyboard controls
- Score tracking
- Game over and restart flow

## Success Criteria

- App runs locally with a passing build
- Gameplay is understandable within seconds
- README explains how to run and verify the app

## Risks

- Overbuilding game mechanics
- Input handling becoming brittle
- UI polish taking priority over reliability
