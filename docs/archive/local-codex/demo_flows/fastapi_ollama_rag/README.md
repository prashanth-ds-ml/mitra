# FastAPI + Ollama RAG Demo

This demo shows a local RAG application built with FastAPI and Ollama.

## Demo goal

Prove that the agent can assemble a small backend app with retrieval, local model usage, and clear operator instructions.

## Run shape

```bash
agent start "Build a local RAG app using FastAPI and Ollama"
```

## Acceptance

- FastAPI service starts locally
- Retrieval is visible in the request path
- Ollama is the only model dependency
- README explains how to run and inspect the system
