# Phase 10 Demo Flows

This directory contains the portfolio-oriented demo packs used to close Phase 10.

Each pack is intentionally small and repeatable:

- `PRD.md`
- `IMPLEMENTATION_ORDER.md`
- `README.md`
- `session_log.md`
- `decision_journal.md`

These are the artifacts the demo flows should produce or update during a run. The markdown sources are committed here so the structure stays stable and easy to review.

## Demo packs

- `snake_game_react/` - React snake game showcase
- `fastapi_ollama_rag/` - local RAG app showcase
- `pomodoro_react/` - React Pomodoro timer showcase
