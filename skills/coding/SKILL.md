# Coding

## Workflow

1. Clarify the target behavior and constraints.
2. Inspect the relevant files and nearby patterns.
3. Make the smallest coherent change.
4. Run the most relevant tests first.
5. Fix any regressions before broadening scope.

## Output

- What changed
- Why it changed
- What was tested
- Remaining risks
