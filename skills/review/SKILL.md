# Review

## Workflow

1. Identify behavioral changes.
2. Check for correctness, safety, and compatibility risks.
3. Verify the test surface matches the change surface.
4. Lead with any blocking issues.

## Output

- Findings in severity order
- Open questions
- Short summary only if needed
