# Debugging

## Workflow

1. Reproduce the failure with the shortest possible command.
2. Read the error and trace the failing path.
3. Identify the first incorrect assumption.
4. Make one targeted fix.
5. Re-run the failing test or command.

## Output

- Symptom
- Root cause
- Fix
- Verification
