# RAG

## Workflow

1. Separate ingestion from retrieval.
2. Validate document chunks and metadata.
3. Make retrieval behavior explainable.
4. Test empty, partial, and noisy corpus cases.

## Output

- Ingestion path
- Retrieval path
- Evaluation notes
